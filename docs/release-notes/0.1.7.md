# LearnHub 0.1.7

内置智能体现在可以串联应用命令。比如说「查找所有包含‘合成示例’的笔记，把这批笔记移到‘复习’文件夹」，智能体可以翻完各页，把汇总的笔记 ID 直接传给批量移动命令。

- 应用命令目录提供 **187 条命令**，可从内置智能体和 CLI 发现、查看参数并调用。版本包含 12 条资料抽取后端命令及其实现。扫描件识别可接入单独部署的本地 OCR 侧车。[本地 OCR 部署与命令](https://github.com/luyiyanyumu/LearnHub/blob/v0.1.7/docs/document-ocr.md)
- 管道可以引用前序结果并提取列表字段。笔记和资料查询支持自动翻页，保留查询条件并汇总各页。只读命令可以按顺序逐项执行，例如逐篇读取笔记详情，再把结果传给后续步骤。
- 管道最多 8 步、64 次只读调用，单个自动翻页步骤最多汇总 500 条。检测到分页不一致、读取失败或超限时，管道停止。管道可在末尾放一条写入命令，点击确认后按预览中固定的参数执行。
- 内置智能体使用 `note.page`、`file.page`、`category.tree` 和 `code.search` 查询笔记、资料、分类和代码库。已保存的工作流仍可通过 `query_notes`、`list_files`、`list_categories` 和 `search_code` 调用原工具。原文核验、完整代码读取和带版本检查的笔记编辑沿用专用工具。

[应用命令与管道用法](https://github.com/luyiyanyumu/LearnHub/blob/v0.1.7/cli/README.md#应用操作与内置智能体)

## 安装与升级

npm 包 `@luyiyanyumu/learnhub@0.1.7` 使用对应版本的前后端镜像，支持 Linux amd64 和 arm64 容器。已有实例可沿用 npm 启动器的更新流程，更新前会备份数据库、资料、技能和配置。已有实例中的技能提示词随持久卷保留。
